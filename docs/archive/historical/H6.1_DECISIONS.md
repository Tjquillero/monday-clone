# Histórico de Decisiones — Hito 6.1

**Estado**: 🔒 CLOSED / VERIFIED / CERTIFIED / FROZEN
**ADR**: ADR-0013 v1.2 (Proyección, Diagnóstico y Reprogramación Gobernada con OCC)

## Resumen Ejecutivo
El Hito 6.1 congeló la arquitectura del motor de reprogramación y programación de mantenimiento (`MaintenanceScheduleService` y `RoutineScheduler`), introduciendo:

1. **Read Model Consultivo Puro**: `evaluateMaintenanceScheduleView` que proyecta ocurrencias sin mutar la base de datos.
2. **Validator Sextuple Compuerta**: `validateRescheduleCommand` que evalúa viabilidad operativa y reglas de negocio.
3. **Gateway con OCC Condicional**: Basado en `planned_date` + `updated_at` para prevenir colisiones concurrentes.
4. **Inmutabilidad Histórica de `occurrence_key`**: Preservación estricta de trazabilidad sin alterar claves históricas (Opción B).
5. **Append-Only `override_reason`**: Registro inmutable de justificaciones humanas.
6. **Consumo Soberano de Calendario Laboral Colombiano**: `isOperationalWorkingDay` sin mutar capacidades físicas (H4.9).
7. **Aislamiento Estricto H8**: Garantía AST de no modificar contratos congelados previos.
